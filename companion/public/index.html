Set up dictation

Dictation needs permission to use your microphone. Click Test microphone and say a few words. If your Mac asks whether Stream Deck can use the microphone, choose Allow.

No sound came through. To fix it:

  1. and turn on Elgato Stream Deck.
  2. Quit and reopen the Stream Deck app so the change takes effect.
  3. Check that your microphone is selected under System Settings → Sound → Input, and that it isn't muted.
  4. Then test again.

Use as an app

Install deck-time as its own app, with a window and a Dock or taskbar icon, so you never have to find this page in a browser:

  • Edge or Chrome: click the install icon at the right end of the address bar (or the ⋯ menu → Apps → Install this site as an app).
  • Safari on a Mac: File → Add to Dock.

deck-time runs whenever the Stream Deck app is running, so the app is always ready.
