Use as an app

Install deck-time as its own app, with a window and a Dock or taskbar icon, so you never have to find this page in a browser:

  • Edge or Chrome: click the install icon at the right end of the address bar (or the ⋯ menu → Apps → Install this site as an app).
  • Safari on a Mac: File → Add to Dock.

deck-time runs whenever the Stream Deck app is running, so the app is always ready.

Late nights

Working past midnight needs no answer. The timer keeps running and the time is split at midnight onto each day, or kept on the day you started if you choose that above. deck-time only asks once, if a timer from last night is still going in the morning and nothing was logged on it for two hours before then.

Phrasebook

Drafts are instant and use no AI model: shorthand is expanded, verbs go into the past tense, and actions are joined. Teach it your own shorthand below. It also learns from you automatically: when you export, every change you made to a draft is remembered for that matter right away, and everywhere once you've made it twice. Recent corrections count more than old ones.

Task & activity codes

Codes are suggested instantly from keyword rules and from how you've coded before: every export teaches deck-time, and you can give it a head start with past time exported from Intapp. Nothing here uses AI.
